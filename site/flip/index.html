同目录翻页

打开任意图片后，在同一文件夹内上一张 / 下一张，不递归子目录。

  • 触控板双指滑动：一次只切一张
  • 鼠标移到窗口左 / 右约三分之一显示箭头，点击翻页
  • 键盘方向键亦可切换

标注与轻量编辑

Linux / Windows / 国产系统 1.3.0 与 macOS Flip 同一套工具条：画完、裁完、改完，接着翻下一张。

  • 画笔、直线、箭头、矩形、椭圆、高亮、文字
  • 裁剪八个控点；旋转、翻转、调色、改尺寸
  • 微信式文字背景；窄窗用 >> 收起工具

显示与格式

默认缩放：小于窗口 100%，大于窗口适应窗口且居中。

  • macOS 走系统 ImageIO（JPEG / HEIC / PNG / WebP 等）
  • Linux / Windows 走 Qt 图像插件（建议安装 WebP / TIFF 插件）
  • 缩放、拖动查看细节

免费开源

MIT 许可，可自由使用、修改、二次分发。

  • 中英界面可切换
  • macOS 通用二进制：x86_64 + arm64
  • 源码：GitHub akchansun/flipview（含 desktop/ Qt 版）

更新说明 · macOS 0.6.16

2026年11月4日 · 通用包（Intel + Apple Silicon）· 需 macOS 14+

当前正式版是 0.6.16。打开一张图，就可以在 Flip 里翻页、裁剪、画标注、改颜色改尺寸，不必再切到「预览」。

新功能

  • 顶部工具条：翻页、缩放、旋转翻转、裁剪 / 调色 / 改尺寸 / 检查器 / 移除背景、画笔 / 直线 / 箭头 / 矩形 / 圆角矩形 / 椭圆 / 高亮 / 文字、填充、文字背景、颜色、线宽、字号、存储、打印
  • 文字可加微信式彩色圆角背景，字自动用对比色；输入时就能看到底
  • 顶部工具图标悬停显示名称
  • 窄窗口按「预览」排列：主栏加 >> 溢出，点标注才出现第二行画笔和颜色
  • 线宽选择与「预览」相同：横线由细到粗，点开勾选
  • 裁剪可拖八个点、移动选区、Shift 正方形、显示像素尺寸；⌘A 全选，回车或双击裁切
  • 已有文字可再点编辑、改字号；标注可选中后拖动、改色改粗细改填充，形状可拉伸
  • 从剪贴板新建（⌘N）；检查器含 DPI / 相机 / 曝光
  • 向左 / 向右旋转 90°（⌘L / ⌘R）、水平 / 垂直翻转
  • 拷贝、存储 / 存储为（按原图分辨率写入）、打印（⌘P）

修复

  • 标注 / 裁剪手感更接近「预览」：圆形控点、实心箭头、平滑笔迹、细白裁剪框、文字不再粗描边
  • 文字输入结束立刻回到浏览选择光标，不必再点一次工具
  • 文字点一下就能改，输入框贴着字，不再弹出很大一块也抢不走键盘
  • 最细标注是发丝线；点选和选中虚线贴着笔画外边，不再用大包围盒
  • 标注线条粗细可调；选中后再改色/粗细作用在当前项
  • 撤销按操作回退；选中标注时 Delete 不会误删整张图
  • 标注不再画到顶部工具条上面
  • 放大以指针/手势位置为焦点，不再往左跳
  • 访达双击打开后窗口到最前

更新说明 · Linux / Windows / 国产系统 1.3.0

2026年11月4日 · MIT · 需 Qt 6（建议另装 qt6-image-formats-plugins 以便打开 WebP、TIFF）

这次把 macOS Flip 里已经能用的看图、标注和轻量编辑，用同一套界面接到 Linux / Windows / 国产系统。打开一张图，就可以在 Flip 里翻页、裁剪、画标注、改颜色改尺寸，不必再切到别的看图软件。

新功能

  • 顶部工具条与 macOS Flip /「预览」窄窗一致：主栏翻页、缩放、旋转、标注、裁剪；窗口变窄时用 >> 收起其余项；点标注才出现第二行画笔 / 直线 / 箭头 / 矩形 / 圆角矩形 / 椭圆 / 高亮 / 文字
  • 工具图标悬停显示名称
  • 线宽选择为横线由细到粗，点开勾选
  • 文字可加微信式彩色圆角背景，字自动用对比色
  • 裁剪可拖八个点、移动选区、Shift 正方形、显示像素尺寸；Ctrl+A 全选，回车或双击裁切
  • 已有文字可再点编辑、改字号；标注可选中后拖动、改色改粗细改填充，形状可拉伸
  • 从剪贴板新建（Ctrl+N）；检查器显示文件名、像素、大小、格式；有 DPI 时一并列出
  • 向左 / 向右旋转 90°（Ctrl+L / Ctrl+R）、水平 / 垂直翻转
  • 调整颜色（曝光、对比度、亮度、饱和度等）、调整大小（可按比例）
  • 移除背景（按画面边角取样抠透明底，适合纯色底）
  • 拷贝、存储 / 存储为（按原图分辨率写入）、打印（Ctrl+P）
  • 撤销按操作回退；选中标注时 Delete 只删标注，不会误删整张图

沿用

  • 打开一张图，即可在同一文件夹里前后翻页（方向键、工具栏、左右边缘点击、滚轮）
  • 默认缩放：小图按 100% 显示，大图缩小以适应窗口，居中、默认不放大
  • 简体中文 / English，可跟随系统，也可在「查看 → 语言」里切换
  • 帮助菜单「使用提示」（F1）与启动说明相同；「关于」仍在帮助菜单；「访问 Flip 产品页」打开本页
  • Linux 上「前往更新」仍可就地替换当前目录里的 Flip；Windows 或安装目录不可写时改为打开下载页

说明

  • 同一套 Qt 6 源码，Ubuntu / UOS / 麒麟 / Deepin / Windows 共用
  • 不包含 PDF、签名、连续互通、iCloud
  • 帮助提示原文未改
  • 应用内更新读本站 version.json。Linux 当前为 1.3.0，会下载 amd64 的 tar.gz 并就地替换；Windows 打开下载页

Linux / Windows / 国产系统（1.3.0）

Qt 客户端，与 macOS Flip 同一套工具条。预编译包在 GitHub Release desktop-1.3.0（源码目录 desktop/，说明见 更新说明原文）。国内直接下载用本站镜像，文件与 GitHub 上的安装包相同。Gitee 上还没有这个 1.3.0 附件。

Linux amd64（1.3.0） Linux 国内镜像 Windows x64（1.3.0） Windows 国内镜像 GitHub 发布页
  1. Linux amd64：下载 flip-linux-1.3.0-amd64.tar.gz（GitHub 或本站镜像），解压后运行其中的 Flip。目标机需已安装 Qt 6 运行库和 qt6-image-formats-plugins（打开 WebP、TIFF）。安装包在 Ubuntu 22.04 上编译，需要 glibc 2.35 或更高。统信 UOS、银河麒麟、Deepin 若系统满足上述 Qt 6 与 glibc，可用同一包。
  2. Windows x64：下载 Flip-1.3.0-windows-x64.zip（GitHub 或本站镜像），解压后双击 Flip.exe。压缩包里已经带上 windeployqt 收集的 Qt 运行库和 VC 运行库，一般不用再单独安装 Qt。
  3. 从源码编译（可选）：安装 build-essential cmake ninja-build qt6-base-dev qt6-image-formats-plugins（统信 / 麒麟用仓库里的 GCC、CMake、Qt 6），然后 cmake -S desktop -B desktop/build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build desktop/build，运行 ./desktop/build/Flip 图片或目录。

macOS 安装说明

  1. 点上方「下载 macOS 版（0.6.16）」得到 zip，解压得到 Flip.app。本站 download.php 提供 0.6.16 通用包（含标注与轻量编辑）；也可从 GitHub v0.6.16 下载。Gitee 上目前还没有这个 zip。
  2. 拖到「应用程序」，或放到任意位置。
  3. 第一次打开：不要双击。按住 Control 键点击（或右键）Flip.app → 选「打开」→ 再点「打开」。之后即可正常双击。
  4. 若已出现「未打开 Flip / 移到废纸篓」：点「完成」，打开系统设置 → 隐私与安全性，滚到下方点「仍要打开」。
  5. 当前发行包尚未 Apple 公证（需付费开发者账号），因此会有上述提示；源码可在 Gitee 或 GitHub 自行编译。
